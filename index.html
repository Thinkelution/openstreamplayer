Open IPTV playback, without the clutter.

OpenStreamPlayer is a native Electron app for M3U and Xtream IPTV sources. It gives you fast channel search, favorites, movies/series catalog loading, EPG guide matching, and a compact custom player UI with Stop, bitrate, CC, volume, mute, and fullscreen controls.

Download latest releaseView source on GitHub
brew install --cask thinkelution/tap/stream-player

Current macOS builds are ad-hoc signed and may require manual approval in macOS Privacy & Security. The default sample playlist is from iptv-org.

Built for everyday IPTV use

Simple setup, fast browsing, and responsive playback controls for large playlists.

1

M3U and Xtream

Load classic M3U playlists or Xtream credentials. The app uses provider APIs where they are faster than huge M3U downloads.

2

Guide and favorites

XMLTV and Xtream EPG matching, favorites, compact font options, and a channel list optimized for large catalogs.

3

Custom live controls

Clean player controls that auto-hide while watching. Stop tears down the stream instead of merely pausing the video element.

Install

macOS users can install from the Thinkelution Homebrew tap. Developers can clone the source and run the Electron app locally.

Homebrew

brew tap thinkelution/tap

brew install --cask thinkelution/tap/stream-player

From source

git clone https://github.com/Thinkelution/stream-player.git

npm install && npm run dev

OpenStreamPlayer does not include IPTV subscriptions or channel credentials. It opens with the public iptv-org M3U URL as a sample; configure your own legal playlist/source and optional XMLTV guide in Settings for everyday use. Backlink: iptv-org IPTV and iptv-org EPG.
