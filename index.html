Open IPTV playback, without the clutter.

OpenStreamPlayer is a native Electron app for M3U and Xtream IPTV sources. It gives you fast channel search, restored favorites, contextual fullscreen navigation, EPG guide matching, and a compact custom player UI with Stop, bitrate, CC, volume, mute, and fullscreen controls.

Current macOS builds are ad-hoc signed and may require manual approval in macOS Privacy & Security. Settings shows iptv-org only as an example M3U placeholder.

Built for everyday IPTV use

Simple setup, fast browsing, and responsive playback controls for large playlists.

1

M3U and Xtream

Load classic M3U playlists or Xtream credentials. The app uses provider APIs where they are faster than huge M3U downloads.

2

Guide and favorites

XMLTV and Xtream EPG matching, favorites, compact font options, and a channel list optimized for large catalogs.

3

Custom live controls

Clean player controls that auto-hide while watching. Stop tears down the stream instead of merely pausing the video element.

Install

Download OpenStreamPlayer v0.1.22 for macOS, Windows, or Linux, or install the macOS build from the Thinkelution Homebrew tap.

macOS Apple SiliconDMG installer for M1/M2/M3/M4/M5 MacsOpenStreamPlayer-0.1.22-arm64.dmgWindowsSetup installer for Windows PCsOpenStreamPlayer.Setup.0.1.22.exeLinuxPortable AppImage, with .deb also availableOpenStreamPlayer-0.1.22.AppImage

Homebrew

brew tap thinkelution/tap

brew install --cask thinkelution/tap/stream-player

From source

git clone https://github.com/Thinkelution/stream-player.git

npm install && npm run dev

OpenStreamPlayer does not include IPTV subscriptions or channel credentials. It opens with an add-playlist prompt. Settings shows the public iptv-org M3U URL only as an example placeholder; configure your own legal playlist/source and optional XMLTV guide for everyday use. Backlink: iptv-org IPTV and iptv-org EPG. See all release files at GitHub release v0.1.22.

Release changelog

Latest OpenStreamPlayer release notes are kept here with the hosted downloads.

v0.1.22 · Icon and fullscreen guide progress

  • Adds the new OpenStreamPlayer app icon, favicon, website icon, and Apple touch icon.
  • Shows the current EPG program in the fullscreen right-hover channel drawer when guide data exists.
  • Adds a compact progress bar showing how far the current program has advanced.
  • Release assets are available for macOS Apple Silicon, Windows, and Linux.

v0.1.22 · Buffering and fullscreen polish

  • Shows “Starting stream” only before first playback; mid-stream buffering now uses a spinner-only overlay.
  • Tunes HLS buffering, retry, and recovery behavior for smoother playback when a stream stalls or starts slowly.
  • Fullscreen button now toggles to exit-fullscreen while fullscreen is active.
  • Release assets are available for macOS Apple Silicon, Windows, and Linux.

v0.1.20 · First-run and guide improvements

  • Starts with an add-playlist prompt instead of auto-loading a sample playlist.
  • Adds current EPG details in channel rows and fullscreen controls.
  • Preserves existing playlists, favorites, and settings across reinstalls.
